# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, and keep discussion focused on the work. Harassment,
personal attacks, and demeaning or exclusionary behaviour are not acceptable in issues, pull
requests, commit messages, or any other project space.

## Reporting

Report conduct concerns privately to the maintainers via
[GitHub's private vulnerability reporting](https://github.com/Furroxide/UdonSharpCE/security/advisories/new),
which is the available private channel on this repository. Reports are handled confidentially.

Maintainers may edit, remove, or reject contributions that violate this policy, and may block
repeat offenders from the project.
